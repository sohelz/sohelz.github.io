AI MLX — Local AI Code Translator for SuperCollider

2026-04-16
code-lab

AI MLX is a SuperCollider tool that translates natural language shorthand into SuperCollider code using a local LLM running on Apple Silicon via MLX. No cloud API, no internet — everything runs on your machine. Designed and built by Soheil Zarrinpour with the assistance of AI.

What It Does

Instead of typing full SuperCollider syntax, you write shorthand like sin440 0.1 or lpf white 440, and the tool returns clean SuperCollider code: SinOsc.ar(440, 0, 0.1) or LPF.ar(WhiteNoise.ar(1), 440). It understands oscillators, noise generators, filters, envelopes, arrays, patterns, reverbs, delays, math operations, and more — a full dictionary of SuperCollider vocabulary.

You can also use ~sc.("sin440 0.1") to translate and immediately play the result in one step.

How It Works

The tool uses three components working together:

MLX — Apple's machine learning framework optimized for Apple Silicon (M1/M2/M3/M4). It runs large language models locally using the GPU, with no cloud dependency.
mlx-lm — A Python command-line tool for generating text with MLX models. Install it with pip3 install mlx-lm.
Llama 3.1 8B (4-bit) — Meta's open language model, quantized to 4-bit for efficient local execution (~4 GB download on first use).

From within SuperCollider, the script calls mlx_lm.generate as a shell process using SuperCollider's Pipe class. It sends a structured prompt containing a comprehensive dictionary of SuperCollider syntax, along with your shorthand input. The model returns the corresponding SuperCollider expression, which you can evaluate directly.

How to Use It

1. Install mlx-lm: pip3 install mlx-lm
2. Open AI MLX.scd in SuperCollider and evaluate the function blocks.
3. If your Python path differs, update the path in the Pipe.new(...) call. Find yours with which mlx_lm.generate in the terminal.
4. Type shorthand and get code:

~ai.("sin440 0.1")           // → SinOsc.ar(440, 0, 0.1)
~ai.("lpf white 440")        // → LPF.ar(WhiteNoise.ar(1), 440)
~ai.("reverb saw 220 0.2")   // → FreeVerb.ar(Saw.ar(220, 0.2))
~ai.("close to 2 5 10 15 22") // → Array.geom(5, 2, 2)
~ai.("pbind sin rand freq 200 800 dur 0.25")
~sc.("sin440 0.1")           // translates AND plays

Requirements

macOS with Apple Silicon (M1 or later), Python 3, SuperCollider, and mlx-lm. The model downloads automatically on first run.

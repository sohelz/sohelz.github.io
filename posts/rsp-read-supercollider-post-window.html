RSP — Read SuperCollider Post Window

2026-04-16
braille-screen-reader-access-tools

RSP (Read SuperCollider Post Window) is a macOS accessibility tool that reads the SuperCollider Post Window aloud via VoiceOver with a single hotkey. Designed and built by Soheil Zarrinpour with the assistance of AI.

The Problem

When live-coding in SuperCollider, the Post Window constantly prints evaluation results, server messages, and debug output. For a blind or visually impaired user relying on VoiceOver, switching focus to the Post Window to read its content breaks the workflow and wastes valuable time — especially during a performance or a fast coding session.

How RSP Works

RSP is a macOS Automator application wrapping an AppleScript. When triggered by a hotkey, it does the following:

1. Uses System Events to access the SuperCollider process and read the text content of the Post Window.
2. Parses the text into lines and finds the last non-empty line — the most recent output.
3. Sends that line to VoiceOver, which speaks it aloud immediately.

The entire cycle happens in an instant. There is no window switching, no mouse interaction, and no disruption to the coding flow.

Tools Used

macOS Automator — packages the script as a standalone .app that can be assigned a system-wide keyboard shortcut.
AppleScript — interfaces with SuperCollider's UI through the macOS accessibility API (System Events).
VoiceOver — Apple's built-in screen reader, used here to speak the extracted Post Window text.

Setup

Download or build rsp.app from the RSP GitHub page, then assign it a hotkey through System Settings or a tool like Hammerspoon. Make sure VoiceOver is enabled and that both SuperCollider and the Automator app have Accessibility permissions in System Settings.

With one keypress, you hear the latest Post Window output — no context switch, no wasted time.

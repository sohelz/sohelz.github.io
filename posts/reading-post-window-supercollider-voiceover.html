Reading Post Window in SuperCollider via VoiceOver

2026-04-16
braille-screen-reader-access-tools

This is a macOS AppleScript that reads the latest line from the SuperCollider Post Window aloud via VoiceOver with a single hotkey. Designed and built by Soheil Zarrinpour.

The Problem

When live-coding in SuperCollider, the Post Window constantly prints evaluation results, server messages, and debug output. For a blind or visually impaired user relying on VoiceOver, switching focus to the Post Window to read its content breaks the workflow and wastes valuable time — especially during a performance or a fast coding session.

How It Works

The script uses System Events to access the SuperCollider process and read the text content of the Post Window. It parses the text into lines and finds the last non-empty line — the most recent output — then sends it to VoiceOver, which speaks it aloud immediately.

The entire cycle happens in an instant. There is no window switching, no mouse interaction, and no disruption to the coding flow.

Tools Used

AppleScript — interfaces with SuperCollider's UI through the macOS accessibility API (System Events).
VoiceOver — Apple's built-in screen reader, used here to speak the extracted Post Window text.

Setup

Download postwindow.applescript from the voiceover-apple-scripts GitHub repository. Open it in Script Editor to verify or customize it.

To trigger it with a single keypress, assign it a shortcut in VoiceOver Utility: open VoiceOver Utility → Commanders → Keyboard Commander, add a new entry, choose your key combination, and set the action to run the AppleScript.

Make sure VoiceOver is enabled and that SuperCollider has Accessibility permissions in System Settings → Privacy & Security → Accessibility.

With one keypress, you hear the latest Post Window output — no context switch, no wasted time.
